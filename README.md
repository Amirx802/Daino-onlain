# سرور بازی دایناسور

یه سرور Node.js با این امکانات:
- **حساب بازیکن**: ثبت‌نام با شناسه و توکن مخصوص هر بازیکن
- **ذخیره‌ی پیشرفت**: ژنتیک، سکه و دایناسورهای باز‌شده
- **جدول امتیازات**
- **هدیه با شناسه از راه دور**: بدون عوض کردن فایل بازی
- **چندنفره**: با WebSocket، هر نقشه یه اتاق (حداکثر ۳۰ نفر)

## اجرا روی کامپیوتر
```
npm install
ADMIN_KEY=یه-رمز-بلند npm start
```
آدرس تست: `http://localhost:3000/health`

## گذاشتن روی گیت‌هاب و هاست
گیت‌هاب فقط کد رو نگه می‌داره. برای اجرا یه هاست لازمه (مثلاً Render):
1. همین پوشه رو توی یه مخزن (repo) گیت‌هاب بذار. فایل `.env` رو هرگز آپلود نکن.
2. توی Render یه **Web Service** بساز و مخزن رو وصل کن.
   - Build Command: `npm install`
   - Start Command: `npm start`
3. توی بخش Environment این‌ها رو بذار:
   - `ADMIN_KEY` = یه رمز بلند و تصادفی
   - `ALLOWED_ORIGIN` = آدرس بازی‌ت، مثلاً `https://yourname.github.io`
   - `DATA_DIR` = `/var/data`
4. **مهم:** اطلاعات بازیکن‌ها توی فایل `db.json` ذخیره می‌شه. روی پلن رایگان دیسک موقتیه و با هر دیپلوی پاک می‌شه. برای نگه داشتن اطلاعات یه Disk دائمی (Persistent Disk) به مسیر `/var/data` وصل کن. بعداً می‌شه به دیتابیس واقعی عوض کرد.
5. پلن رایگان بعد از مدتی بیکاری می‌خوابه و اولین درخواست کند جواب می‌ده.

بازی خودش رو هم می‌تونی با GitHub Pages بذاری. آدرس سرور باید `https` باشه تا `wss` کار کنه.

## هدیه دادن با شناسه
```
curl -X POST https://YOUR-SERVER/admin/gift \
  -H "x-admin-key: ADMIN_KEY" -H "content-type: application/json" \
  -d '{"id":"1262472778","genes":30,"coins":0,"note":"هدیه"}'
```
بازیکن دفعه‌ی بعدی که بازی `claimGifts()` رو صدا بزنه، هدیه رو می‌گیره (فقط یک بار).

بقیه‌ی دستورهای ادمین:
- `GET /admin/player/:id` برای دیدن اطلاعات بازیکن
- `POST /admin/reset-token` با `{"id":"..."}` برای وقتی بازیکن توکنش رو گم کرده

## نکته‌ی امنیتی
بازی توی مرورگر اجرا می‌شه، پس بازیکن می‌تونه مقدار سکه و ژنتیکی که به سرور می‌فرسته رو دستکاری کنه. سرور فقط مقدارها رو محدود و اعتبارسنجی می‌کنه (سقف ۱ میلیون و فقط دایناسورهای مجاز). اگه جدی می‌خوای جلوی تقلب رو بگیری، باید سکه و ژنتیک رو فقط سمت سرور بدی و کم کنی.

## اتصال به بازی
فایل `client.js` یه کتابخونه‌ی کوچیک برای بازیه (ثبت‌نام، ذخیره، هدیه، امتیاز، چندنفره). آدرس `SERVER` رو توش عوض کن. وصل کردنش به خود بازی هنوز انجام نشده.
