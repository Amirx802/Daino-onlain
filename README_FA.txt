راه‌اندازی سرور آنلاین بازی دایناسوری

۱) این ZIP را از حالت فشرده خارج کن.
۲) پوشه را در یک مخزن GitHub آپلود کن.
۳) در Render گزینه New + > Web Service را بزن و مخزن GitHub را وصل کن.
۴) تنظیمات:
   Build Command: npm install
   Start Command: npm start
۵) Deploy را بزن و صبر کن تا سرویس Live شود.
۶) لینک سایت Render را در دو گوشی/مرورگر باز کن و در هر دو «آنلاین» را انتخاب کن.

آدرس /health باید JSON با ok:true نشان دهد.
مسیر WebSocket این سرور /ws است و پروتکل اتصال موجود در بازی را پشتیبانی می‌کند.
برای اتاق جداگانه می‌توان به لینک سایت ?room=123 اضافه کرد؛ هر دو بازیکن باید یک کد اتاق داشته باشند.

نکته: این ZIP سرور و فایل بازی را آماده می‌کند، اما من نمی‌توانم آن را به حساب Render یا GitHub کاربر آپلود کنم. برای آنلاین شدن واقعی باید آن را روی Render منتشر کنی.


اصلاح اتصال چندنفره: فایل index.html حالا مستقیماً به WebSocket همین سرور (/ws) وصل می‌شود. برای بازی آنلاین، سایت را از آدرس Render باز کنید؛ باز کردن فایل به‌صورت file:// به سرور وصل نمی‌شود. هر دو بازیکن باید همان آدرس سایت و اتاق یکسان را باز کنند.
